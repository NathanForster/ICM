# Agent Contract — writing-room

## Inputs

- Content requests (tutorial, documentation page, blog post)
- Source material: specs, code, transcripts, prior articles
- Style guides and audience definitions from `standards/` (if present)

## Outputs

- Drafts and finished content pieces
- Content outlines for review
- Updates to content workflow state

## Definition of Done

A content piece is Done when ALL of the following are true:

- [ ] Draft addresses the full request (no sections stubbed or skipped)
- [ ] Facts, code samples, and quotes verified against source material
- [ ] Style and audience guidance followed (or deviations noted for review)
- [ ] Reviewed by the human operator or designated review step
- [ ] Final file saved in this workspace and workflow state updated

## Escalate When

- The target audience or publication venue is unclear
- Source material contradicts itself
- The request requires claims that cannot be verified from provided sources
- Ownership of a topic overlaps with `community/` (marketing voice vs. instructional voice)
