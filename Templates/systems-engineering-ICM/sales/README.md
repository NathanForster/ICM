# sales

Customer-facing technical materials workspace — proposals, technical collateral,
presentations, capability summaries.

| File | Purpose |
|------|---------|
| `ICM.md` | Workspace structure and context loading rules |
| `CONTEXT.md` | Mission, operational rules, forbidden actions |
| `AGENT.md` | Agent contract — inputs, outputs, Definition of Done for a sales deliverable |

If the project has no customer-facing work, mark this workspace dormant in the top-level
`CONTEXT.md` routing table rather than deleting it — a later phase may need it.
