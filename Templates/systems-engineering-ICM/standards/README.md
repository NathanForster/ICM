# Standards

Global standards and conventions.

## What Belongs Here

- Coding standards (language, style, lint configuration rationale)
- Naming conventions (files, branches, REQ IDs, artifacts)
- Documentation conventions (templates to use, review requirements)

## Conventions

- One standard per file, with an owner and effective date in a header line
- Workspace CONTEXT.md files reference applicable standards; agents load them
  as part of "applicable standards" during context loading
- Changing a standard is a recorded decision — link the ADR in `decisions/`
