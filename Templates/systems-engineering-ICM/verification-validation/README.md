# Verification and Validation

Validation workflows and evidence.

## What Belongs Here

- **Test evidence** — reports, logs, and results referenced by the requirements
  register when advancing a requirement to `Verified`
- **Validation records** — records of demonstrations, analyses, and inspections
  (the four qualification methods: Test, Demonstration, Analysis, Inspection)
- **V&V plans** — what will be verified, by which method, at which milestone

## Conventions

- Name evidence files so the REQ ID is visible: `REQ-42-test-report.md`
- A requirement may only be marked `Verified` in the register when evidence
  exists here, in `src/tests/`, or the human operator confirms manual verification
- For formal test deliverables (STP, STPr, STR, RTVM) see the DIDs library in
  the ICM templates repository (`Templates/advanced-options/DIDs/GUIDE.md`)
