# documentation

Technical documentation workspace — user manuals, development plans, validation
documentation, release notes, and formal (DID-governed) deliverables.

| File | Purpose |
|------|---------|
| `ICM.md` | Workspace structure and context loading rules |
| `CONTEXT.md` | Mission, operational rules, and how formal deliverables are generated from the SE-Deliverables library |
| `AGENT.md` | Agent contract — inputs, outputs, Definition of Done for a document |

Generated deliverables live in the project's `docs/` (map: `docs/DELIVERABLES.md`); this
workspace owns their production and review.
