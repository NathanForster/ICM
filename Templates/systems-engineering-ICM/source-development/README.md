# source-development

Software engineering and automation workspace — the single authoritative location for
source code, implementation briefs, validation briefs, and pipeline stage outputs.

| File / folder | Purpose |
|------|---------|
| `ICM.md` | Workspace structure and context loading rules |
| `CONTEXT.md` | Mission, mandatory pipeline sequence, artifact naming, backfill policy |
| `AGENT.md` | Agent contract — inputs, outputs, per-requirement Definition of Done |
| `workflows/` | Stage folders `03-implementation/` and `04-validation/` with their stage contracts; see `workflows/README.md` for the numbering convention |

Source code itself lives in the project's `src/`; this workspace owns the process
artifacts around it.
